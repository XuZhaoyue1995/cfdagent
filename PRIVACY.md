# Privacy information

Prepared for CFDAgent 0.2.0 on 30 September 2026. Publisher: **Zhaoyue Xu**.

## The plugin package

CFDAgent contains professional instructions, reference notes, manifests,
documentation, and icon assets. It includes no publisher-operated server,
telemetry client, advertising, analytics, or separate account system.
Installing the package does not by itself send project files or conversations
to the publisher. The publisher has no automatic access to your host account
or project through this package.

## Host applications and computing services

The AI application you use processes conversations, supplied files, and tool
activity under its own settings and policies, including the
[OpenAI Privacy Policy](https://openai.com/policies/privacy-policy/) or
[Anthropic Privacy Policy](https://www.anthropic.com/legal/privacy), as applicable.

Within your instructions and host permissions, the agent may inspect project
files, save case files and working notes, write helper scripts, open reference
websites, and run computations locally or on resources you provide. Host or
external services may process or retain those inputs and outputs. Their
policies and account settings govern that processing; this package does not
promise that everything remains on your computer.

## Support correspondence

If you voluntarily open a [GitHub issue](https://github.com/XuZhaoyue1995/cfdagent/issues),
the publisher can see the information you submit and the public profile
information GitHub shows. Public issues and attachments are visible to others.
Provide only the material needed to explain your question, and omit secrets
and confidential project data. GitHub processes and retains this information
under its own [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

The publisher uses support correspondence to answer questions and investigate
reported problems. This package provides no separate support-data store or
automatic data-deletion schedule.

## Your controls

You choose what project material to share and which host tools to authorize.
You can disable or uninstall CFDAgent and manage files you control. Manage
host-stored data and GitHub contributions through the relevant service's
controls; uninstalling the plugin does not automatically delete those records.

## Contact and updates

Questions about this document can be raised through the project's GitHub
issues. Updates will be identified in this file. This document describes the
plugin package and does not replace the host provider's privacy policy.
